# UX-11 — compact panels, popups and "More" for long explanations

**Owner request (2026-10-21):** keep shrinking panels and popup menus to maximise screen space for content; move long
messages behind dropdowns, but never hide messages users must see for policy; specifically shrink the Profile count
panel (Seki / Riding / Crew / Squad) and the Local polls. Builds on UX-09 / UX-10 (Codex) and keeps the UX-08 theme.
**Executor:** Claude Code root session; independent read-only review subagent.

## Changes

| Where | Change |
| --- | --- |
| Profile count row (`ProfileStatRow`) | One line; Join Crew is a 30pt control at the end (hitSlop 8 → 46pt target) instead of a 44pt circle under Crew with spacers in every column; mutual Teammates badge keeps minWidth 44. ~180pt → ~60pt. |
| Profile section tabs (`AthleteProfileView`) | All sections on one row, icon over label, 44pt tall (Team no longer wraps to its own row). |
| Local poll (`CheerPollCard`) | Cheer count in the header, matchup inline with the question, thinner bar, percentages on the vote buttons (and in their spoken labels). ~300pt → ~165pt. `COMPLIANCE_POLL` stays in full (12pt). |
| Game page | `GameVenueCard`, `NotificationPrefsBar`, `PlayCard` (44pt jersey block), `TabSwitcher`: smaller padding and type. |
| All popups | `useSheetFrame` padding md/xs/sm, `MENU_METRICS` radii 24/16/14, `MenuChrome` steps 32pt, donate title 19pt. Controls stay 44pt. |
| Long explanations | New `UI/MoreText` (clamp + More/Less, full text to screen readers) on the Filmer card, Beyond header, notifications explainer, Rally story, athlete bio and fan page ledes. Role-home ledes stay plain (admin-editable, may mention consent/payouts). |

**Never collapsed:** `COMPLIANCE_*`, held notice, 90 / 10, tip-for-Tapua'i line, rights confirmations, age gate,
`WORKOUT_IDEAS_LINE`, Beyond's data-rights/paused note. A guard test (`MoreText.test.tsx`) scans every MoreText call
site and fails if policy copy is wrapped.
