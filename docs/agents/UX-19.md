# UX-19 — compact, consistent fan tabs

**Owner request (2026-11-23):** panels should be smaller and consistent; the notification area's fonts, panels and
spacing are too spacious; content should sit closer together; the navigation should transition well with its
background; fonts should be consistent across tabs; some screens are too plain.

**Owner decisions (2026-11-23, Claude Code session):**

1. Text stays **14/20 body and 12/16 captions** (the UX-12 rule). Space comes out of layout, not type size.
2. Navigation becomes **one frosted bar that adapts** to the screen behind it.
3. "Less plain" means all four: **one heading style**, **sport-theme accents**, **depth and tint**, **motion polish**.
4. Approach **B — hand-tune each screen.** No new shared components; the same values are applied by hand in the
   existing files.

Builds on [UX-18](UX-18.md) (dock 44pt, Activity rows, NotificationInbox insets). UX-18's receipts stay as they are.

## Baseline (observed 2026-11-23, Expo web 390×844, signed in as Demo Fan)

| Surface | Observation |
| --- | --- |
| Bottom bar | Five separate white tiles on a grey strip; reads as a hard white slab over Home's dark video feed. Each item paints its own `colors.surface` box, which hides the bar's existing `BlurView`. |
| Activity → Notifications | Inbox / Archived / Refresh are three full-width bordered 44pt buttons, heavier than the content. "More" floats below the text line. |
| Activity → Your updates | One bordered card per gift row, each with its own padding. |
| Section headings | Four styles: plain bold (Activity), green bar (Local), gold uppercase kicker (Home, Spotlight), large display (Profile). |
| Local | Chunky Games / Polls / Boosters buttons and region chips; tall live score cards (HOME/AWAY label, team, school on separate lines). |
| Spotlight | Two-line subtitle; board filters wrap onto two rows of 44pt bordered pills. |
| Profile | A whole card for a one-word Story; Share alone on its own row. |
| Page headers | Title + underline + subtitle use about 120pt before any content. |

Root cause: `TYPE` is used about 1,080 times, but spacing is hard-coded about 1,680 times (`space.*` only 65), so
each screen drifted on its own.

## Part 1 — rules applied by hand (approved)

| Element | UX-19 rule |
| --- | --- |
| Page header (`ScreenHeading`) | About 84pt: title stays `TYPE.display`, shorter underline, 4pt gap, subtitle `TYPE.body` capped at 2 lines. |
| Section heading | One style everywhere: `TYPE.section` in `FONT.displayBold`, optional 16pt jade icon, optional count or "See all" on the right; 12pt above, 6pt below. Over dark video surfaces the same style uses `onVideo` ink. |
| Panel | 12pt padding, card radius 14, border **or** soft shadow (not both), 8pt between panels. |
| Repeated items | One card holding the rows, hairline dividers, 10pt vertical row padding. |
| Button rows | One tinted track with a jade pill for the selected item. Each segment keeps `minHeight: 44`. |
| Filter chips | Borderless tinted chips on one horizontally scrolling row. Each chip keeps a 44pt touch height. |
| Text | Unchanged scale: `TYPE.body` 14/20, `TYPE.caption` 12/16; font scaling stays on. |
| Navigation | One continuous frosted bar; dark glass over Home video, light glass elsewhere; content fades over about 24pt above the bar; the active tab gets a jade pill behind its icon that slides between tabs (no slide with Reduce Motion). 44pt targets and measured safe-area clearance unchanged. |

**Checks:** new/updated Jest cases in FanTabBar, ScreenHeading, NotificationInbox, MoreText, tab-story-states, GameCard, LocalTab, LeaderboardsBoard, AthleteProfileView and theme/fonts. **Independent review (fresh Opus reviewer, whole branch) and fixes:** C1 — on native, the heading-line Refresh and the inline More toggle overlapped (web ignores `hitSlop`, which hid it); Refresh moved to the end of the segment track and the toggle lost vertical slop. I1 — Home's inactive labels on dark glass were ~2–3:1 over bright video; now full on-video ink, tint 0.86 and a 0.9 softened floor. I2 — the 24pt fade covered scrolled-to-bottom content; the fade height is now reported with the dock height. I3 — the venue could squeeze into a letter column; it keeps a 140pt basis. Each fix has a test that failed first. Deferred minors are listed in the session report.

**Review follow-ups (minors, same day):** Reduce Motion now has a behaviour test (no spring under Reduce Motion, spring otherwise) and Reduce Transparency asserts no blur layer; the Home pill derives from `FOCAL.neonJade` at 16%; the fan kicker badge centres on the title line; unused styles removed; the Local search input carries `fontSize` only (no iOS lineHeight clip); the paging hint says "The refresh button…"; Activity/Local headings sit 12pt above / 6pt below; "Boards · This week" is announced as a heading. The Home kicker keeps its heading role and as-typed case (matching the Look desk preview). A one-line Spotlight subtitle was tried and reverted: its 44pt More row made the header taller than two plain lines.

**Not verified here:** native Android/iOS rendering and blur, real device large-text settings (Expo web does not apply system font scaling), Drip's chips (Drip is paused in this environment), and an enlarged-text capture: this Mac has no iOS simulator and Expo web does not apply system text scaling, so 200% text needs the owner's phone (Settings → larger text). Profile Share stays in its own row as a compact control rather than moving into the hero.
